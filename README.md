# Todo List

Умный список задач на Vue 3 + Pinia + Vuetify 3 + TypeScript.

## Запуск

```sh
npm install
npm run dev
```

### Сборка для продакшна

```sh
npm run build
```

### Линтинг

```sh
npm run lint
```

## Стек

- **Vue 3** (Composition API, `<script setup>`)
- **Pinia**
- **Vuetify 3** 
- **TypeScript** 
- **Vite**
- **Vue Router**

## Функциональность

- Создание, редактирование и удаление задач
- Поля задачи: название (обязательно), описание (опционально), статус, приоритет
- **Статусы:** `Todo` / `In Progress` / `Done`
- **Приоритеты:** Низкий / Средний / Высокий — цветовая индикация через чипсы
- Табличное отображение (`v-data-table`)
- Фильтрация по статусу и приоритету
- Поиск по названию и описанию
- Валидация формы (название обязательно)
- Персистентность через `localStorage`
